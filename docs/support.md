# Support

## How to get help

1. Check [FAQ](./faq.md) and [user guide](./user-guide.md).
2. Run `aftermath doctor` and `aftermath config validate`; include their output in reports.
3. Open a GitHub issue with:
   - Aftermath version (`aftermath version`)
   - OS / Node version
   - Minimal reproduction or fixture
   - Relevant receipt paths (redact secrets)

## Bug reports

Use the bug report issue template. Attach `summary.json` when possible (not full logs if sensitive).

## Feature requests

Use the feature request template. Prefer evidence-backed verification capabilities over “more AI”.

## Security issues

Do **not** file public issues for undisclosed vulnerabilities. See [SECURITY.md](../SECURITY.md).

## Commercial / sponsorship

Sponsor development via GitHub Sponsors or thanks.dev — see repository funding links. There is no paid SLA in v0.3.
