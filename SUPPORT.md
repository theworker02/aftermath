## Before opening an issue

```bash
aftermath version
aftermath doctor
aftermath config validate
```

Include OS, Node version, and a minimal reproduction when possible.

## Response expectations

This is an indie / open-source project. Best-effort responses; no contractual SLA in v0.3.x.
